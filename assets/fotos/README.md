# Fotos de las tarjetas del inicio

Pon aquí una foto por técnica o área. El nombre del archivo indica a qué tarjeta va:

| Archivo | Tarjeta |
|---|---|
| `vib.jpg` | Vibraciones |
| `tri.jpg` | Tribología |
| `pnd.jpg` | Pruebas no destructivas |
| `mot.jpg` | Motores |
| `int.jpg` | Interruptores |
| `tra.jpg` | Transformadores |
| `bat.jpg` | Bancos de baterías |
| `rel.jpg` | Relevadores |
| `envase.jpg` | Consulta por área · Envase |

- Formato `.jpg`, `.png` o `.webp`.
- Horizontal, de unos 1200 × 450 px. La tarjeta recorta al centro.
- Que pese menos de 250 KB, porque cada foto se incrusta dentro de la página.
- Mientras una técnica no tenga foto, su tarjeta muestra el logo.
- Después de agregar o cambiar fotos, compila con `python scripts/build.py`. En Netlify esto se hace solo al subirlas a GitHub.
- Las fotos solo van en la versión archivo y en Netlify; la versión Artifact no las lleva.
